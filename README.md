# 📌 Nome del Progetto

Progetto molto didattico di un gioco rpg.
Devi muoverti in una matrice di gioco infestata di Nemici e Oggetti.
Il tuo obbiettivo è quello di eliminare tutti i Nemici.
Per farlo dovrai per forza raccogliere almeno qualche Oggetto!

---

## 🚀 Come eseguire il progetto

### Prerequisiti
- Java 25 (LTS)
- Gradle

### Istruzioni

```bash
git clone https://github.com/RiccardoRunci/Progetto_00.git
cd Progetto_00
```

### Build del progetto
```bash
./gradlew build
```

### Esecuzione
```bash
./gradlew run

```cmd di windows
gradlew.bat run

```powershell di windows
./gradlew.bat run

```NOTE:
1)Se si esegue su un terminale cmd di windows, prima di eseguire il programma, digitare "chcp 65001".
  Serve per dire al cmd di usare la codifica UTF-8. Perchè il terminale di intellij salta questa cosa.
  Anche se l'ide intellij è impostato su utf8, non funziona. Continua a fare segni strani.
  Se il comando viene digitato nel terminale di intellij (indifferentemente se è selezionato "Windows powershell" o "local")
  comunque non funziona.
2)Se si esegue in un terminale powershell (a parte, non quello compreso in intellij) Puoi usare anche "chcp 65001",
  Non funziona uguale.
```

## 🤖 Uso di strumenti di AI


È importante dimostrare che:
* il codice è stato **compreso**
* l’AI è stata usata come **supporto**, non come sostituto
---

📌 Per una descrizione più dettagliata dell’uso dell’AI, utilizzare la **Wiki del repository**.


### Esempi :

* Utilizzato ChatGPT per:

  * comprendere concetti teorici (es. differenza tra classi e oggetti)
  * chiarire errori di compilazione
  * suggerimenti su struttura del codice

* Utilizzato Copilot per:

  * autocompletamento di metodi semplici
  * generazione di codice ripetitivo (es. getter/setter)

* Utilizzato ChatGPT per generare una prima versione di una funzione, poi:

  * modificata e adattata manualmente
  * testata e corretta personalmente

---

Oppure:
- Non sono stati utilizzati strumenti di AI
